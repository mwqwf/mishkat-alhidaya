# مشكاة الهداية 📚

**Mishkat Al-Hidaya** — مكتبة إسلامية رقمية للجوال، مفتوحة المصدر.

## الفكرة والغرض

تطبيق جوال (React Native / Expo) يقدّم مكتبة كتب ومواد صوتية إسلامية بواجهة عربية كاملة. بُني ليكون قناة نشر معرفي مجانية: يتصفح المستخدم الأقسام والكتب، يقرأ ويستمع، ويحمّل المحتوى للاستخدام دون اتصال (Offline-first)، بينما يدير المشرفون المحتوى من داخل التطبيق نفسه عبر لوحة إدارة مدمجة.

## أبرز الميزات

- 📖 تصفّح مكتبة كتب مصنّفة بأقسام، مع بحث محسّن بالعربية.
- 🎧 مشغّل صوتيات متكامل (تشغيل، استئناف، قوائم).
- ⬇️ تنزيل الكتب والصوتيات مع استئناف التحميل ودعم الملفات الكبيرة.
- 📴 عمل كامل دون اتصال بعد التنزيل (تخزين محلي + مزامنة).
- 🛠️ لوحة إدارة مدمجة: رفع المحتوى، إدارة الأقسام، الإحصاءات.
- ▶️ تكامل يوتيوب لعرض المرئيات.

## البنية التقنية

| الطبقة | التقنية |
|---|---|
| الواجهة | React Native + Expo |
| قاعدة البيانات | Cloud Firestore |
| الملفات | Firebase Storage |
| التخزين المحلي | Realm / AsyncStorage |
| البناء | EAS Build |

## ⚠️ حالة المشروع

هذا المستودع **مفصول عن أي قاعدة بيانات تشغيلية** — قاعدة البيانات الأصلية حُذفت نهائياً، ولا يحتوي الكود على أي مفاتيح أو أسرار. المشروع منشور كمصدر تعليمي/مرجعي ولإعادة الاستخدام.

## التشغيل

1. `npm install`
2. أنشئ مشروع Firebase خاصاً بك (Firestore + Storage).
3. ضع إعدادات مشروعك في `config/firebase.js` أو عبر متغيرات بيئة `EXPO_PUBLIC_FIREBASE_*`.
4. `npx expo start`

بنية Firestore المتوقعة موثّقة في ملفات `*_README.md` داخل المستودع (توثيق تطويري تفصيلي لكل ميزة).
